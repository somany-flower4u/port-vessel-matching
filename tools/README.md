# 도구

| 파일 | 내용 |
|---|---|
| `decode_lb.py` | 리더보드 점수(소수 10자리)를 한글·비한글 오답 수로 역산합니다. 한쪽 오답 수를 알면 `--ko K` 또는 `--en E`로 다른 쪽을 구합니다. |
| `pack_stream.py` | 패키지 폴더를 제출용 zip으로 묶습니다. 16 MB 단위로 스트리밍하므로 수 GB짜리 LLM 패키지도 메모리 8 GB 맥에서 묶을 수 있습니다. |
| `verify_zips.py` | zip 전체의 CRC를 검사하고, 원본 폴더와 파일 수·크기를 대조합니다. |
| `submit.py` | DACON 공식 `dacon_submit_api` 클라이언트로 코드를 제출합니다. 토큰과 팀명은 환경 변수 `DACON_TOKEN`, `DACON_TEAM`에서만 읽습니다. |

## 사용 시 주의

- `dacon_submit_api`는 DACON이 배포하는 패키지입니다. 대회 안내에 따라 설치하세요.
- 토큰은 파일에 저장하지 말고, 실행할 때만 환경 변수로 넘기세요.
